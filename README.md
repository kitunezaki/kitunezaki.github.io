# トマム スキーシミュレーター

星野リゾート トマムの地形を、国土地理院の標高データ（DEM）に基づいて再現したブラウザで遊べるスキーシミュレーターです。実在のシルバーベル→ビギナーズチョイスのコースを、山頂から麓まで滑走できます。

## 遊び方

- ブラウザで開けばすぐ滑走が始まります（タップ／ドラッグでターン、自動で加速します）
- **Cキー／カメラボタン**: 視点切替（チェイス／一人称／ドローン）
- **Hキー／HUDボタン**: コース名・標高・速度の表示 ON/OFF
- **音ボタン**: 風の音とカービングの雪音（Web Audio合成）の ON/OFF。音は最初のタップで始まります

## 技術メモ

- Three.js製、単一HTMLファイル（約2MB）にすべて内包
- リフト6基・コース10本を公式情報の位置・長さで配置、水の教会やザ・タワーなどの建物も再現
- 滑走の進行に合わせて昼→夕景へ光が変化します

*個人プロジェクトとして作成したファンメイドのシミュレーターです。*
